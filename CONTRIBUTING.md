# Contributing

Use Node.js 22+, run `npm ci`, `npm run build`, and `npm test` before submitting changes.

A task is complete only when its explicitly configured acceptance rule passes or a human confirms it. Do not add automatic completion based solely on an agent's self-report or an expired deadline.

Keep credentials and user data outside version control. Never weaken the loopback binding, origin checks, evidence directory restrictions, or stale-result protection to simplify a connector. New connectors must document their evidence source and failure behavior.

For bug reports include reproduction steps, sanitized example evidence, Node/OS versions, and expected versus actual outcome. Do not attach `data/token`, account session files, private evidence, or the user's database.
