# Dayproof v0.2.0 · 原生 Mac 悬浮计划与小猫年糕

这是早期**源码预览版**，通过 GitHub 开源发布，MIT 许可。尚无经过 Developer ID 签名、公证的 `.app` / `.dmg` 安装包；此处的 Source code 下载项是源码，需要自行构建。无需 App Store 或 Apple Developer 付费会员。

## 这个版本可以做什么

- 原生 SwiftUI / AppKit 日计划：日期、截止时间、优先级和预计用时。
- 菜单栏进度与可拖动、收起、置顶的悬浮小窗。
- 桌面小猫年糕：摸摸、喂小鱼干、完成庆祝、安静模式和本地宠物素材导入。应用图标也使用年糕。
- 文件存在、指定文本、JSON 状态、Markdown 清单等本地代码验收；检查通过后自动打勾并保存依据。
- 论文笔记和邮件草稿的结构检查，默认由用户最终确认。
- MCP 接口可供支持它的工具写入计划；可选 Ollama 生成计划草稿。

## 在自己的 Mac 上运行

需要 Git、Node.js 22+、npm、Python 3 和 Apple Command Line Tools。Swift 界面最低目标为 macOS 13，目前在 Apple Silicon Mac 上实测。

```sh
git clone --branch v0.2.0 https://github.com/airesearchjishengyin/dayproof.git
cd dayproof
npm ci
npm run desktop:build
open build/Dayproof.app
```

无需完整 Xcode、API key 或浏览器。完整说明、截图及接入方法见[仓库首页](https://github.com/airesearchjishengyin/dayproof/tree/v0.2.0)与[使用说明](https://github.com/airesearchjishengyin/dayproof/blob/v0.2.0/docs/user-guide.md)。

## 当前边界

后台验收不调用 LLM 或 decision model。代码只检查用户约定的证据条件；README 勾选不等于开发质量通过测试，论文笔记存在不等于读懂，邮件草稿也不等于已发送。缺少可读证据或需要语义判断的任务，使用手动确认。

应用必须运行、电脑未休眠，才会定时检查。关闭主窗口后仍在菜单栏运行，从菜单栏退出会停止自有后端。任务存本机；用户主动接入的外部 AI 客户端或远程模型服务遵循各自的数据处理方式。暂无开机自启、任意第三方应用自动连接或通用桌面行为验证。

App Store 上架暂缓，当前以 GitHub 开源与改善试用体验为主。

欢迎通过 [Issues](https://github.com/airesearchjishengyin/dayproof/issues) 反馈最希望自动打勾的任务及不含隐私的证据示例。
