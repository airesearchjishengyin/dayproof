# 小红书发布文案

## 标题

给待办装了只猫，还能帮我自动打勾🐾

## 正文

每天早上列一堆计划，晚上才发现：
有些忘了做，有些做完了忘了勾。

于是我做了一个 Mac 桌面小工具，叫 Dayproof。

它可以悬浮在桌面上，也能从菜单栏随时打开。写下今天的任务和截止时间，工作时抬眼就能看见，不用再开一个浏览器页面。

旁边还住着一只小猫「年糕」🐈
可以摸摸、喂小鱼干，完成任务会陪你庆祝。没做完也不会扣分，更不会因为你忙而饿坏。

我最想做的功能，是让一部分任务自己打勾：

📄 约好的文件已经保存 → 检查文件是否存在
✅ 项目进度里的指定条目勾上了 → 同步完成状态
📚 论文笔记写好了 → 检查是否覆盖指定论文和约定结构
✉️ 申请邮件草稿写好了 → 检查收件人、主题和基本正文

笔记和邮件默认还是请你最后确认。你也可以自己决定：满足这些条件，就算今天完成了。

这些后台检查用代码，不会隔几分钟偷偷调用一次大模型。阅读有没有读懂、邮件写得好不好，以及取快递这类暂时拿不到记录的事情，就留给自己确认。

如果你平时用 Codex、Claude Code，也可以通过 MCP 让它们把计划写进来，少在几个工具之间来回复制。

现在已经开源，任务保存在本机，MIT 许可。目前支持 macOS 13+，还是早期版本，需要从源码构建。

项目地址：
https://github.com/airesearchjishengyin/dayproof

想先把它做成一个自己每天愿意打开的小工具。
如果是你，最希望哪一种任务能自动打勾？
